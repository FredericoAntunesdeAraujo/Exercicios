Bloco 01

JavaScript na Web

Antes de escrever qualquer linha de JS, precisamos entender onde ele vive, como o navegador o executa e quais ferramentas vamos usar.

O papel do JavaScript

No desenvolvimento web, as três linguagens trabalham juntas com papéis distintos:

LinguagemPapelAnalogia
HTMLEstrutura e conteúdoO esqueleto e os ossos
CSSApresentação e estiloA roupa e a aparência
JavaScriptComportamento e interatividadeO cérebro e os músculos

Como incluir JS no HTML

Existem três formas de incluir JavaScript em uma página HTML. Cada uma tem seus casos de uso:

1. Inline — dentro de uma tag HTML

O JS é escrito diretamente no atributo do elemento. Funcional para ações muito simples, mas mistura estrutura e comportamento no mesmo lugar.

html — inline 
<button onclick="alert('Olá!')">Clique</button>

2. Interno — dentro da tag <script> no HTML

O código JS fica dentro de uma tag <script> no próprio arquivo HTML. Útil quando o JS é específico daquela página e não precisa ser reutilizado.

html — interno 
<script>
  console.log("JS interno");
</script>

3. Externo — arquivo .js separado

O JS fica em um arquivo .js separado, linkado com a tag <script src="">. Separa o código HTML do JavaScript e permite reutilizar o mesmo arquivo em várias páginas.

html — externo 
<script src="./app.js"></script>
📌

Independente da forma escolhida, a posição do <script> importa. Colocado no <head>, o JS executa antes do HTML carregar. Colocado antes do </body>, o HTML já está disponível quando o JS rodar.

O console — sua principal ferramenta

O console.log() é o print/System.out.println do JavaScript. Pressione F12 → aba Console para ver as saídas.

javascript 
console.log("Olá, JavaScript!");
console.log(42);
console.log(true);
console.warn("Isso é um aviso");   // amarelo
console.error("Isso é um erro");  // vermelho

Sintaxe e Variáveis

Você já conhece o conceito de variáveis de Java e C#. O JS tem algumas diferenças importantes que precisamos destacar.

let, const e var

Palavra-chaveUsoEscopoReatribuição
constValor que não muda — use sempre que possívelBloco {}❌ Não
letValor que vai mudarBloco {}✅ Sim
varLegado — não useGlobal/função✅ Sim
javascript 
const nome = "Ana";      // não vai mudar — use const
let contador = 0;       // vai mudar — use let

contador = 1;           // ✅ permitido com let
nome = "Carlos";         // ❌ erro! const não pode ser reatribuída

Tipos de dados

TipoExemploDescrição
String"Olá", 'JS'Texto
Number10, 3.14, -5Números (inteiros e decimais juntos)
Booleantrue, falseVerdadeiro ou falso
Undefinedlet x;Declarada mas sem valor atribuído
NullnullAusência intencional de valor

A pegadinha do == vs ===

Esta é a diferença mais importante do JS em relação ao Java/C#:

javascript — use sempre === 
console.log(5 ==  "5"); // true  — compara só o valor (coerção de tipo)
console.log(5 === "5"); // false — compara valor E tipo ✅ recomendado

console.log(0 ==  false); // true  — 0 é "falsy"
console.log(0 === false); // false — 0 é Number, false é Boolean
⚠️

Use sempre === e !==. O == faz conversão automática de tipos e causa bugs difíceis de encontrar. Em Java/C# isso não existe porque as linguagens são fortemente tipadas.

Template Literals — concatenação moderna

Em vez de juntar strings com +, o JS moderno usa template literals com acento grave e ${}:

❌ Jeito antigo
const msg = "Olá, " + nome +
  "! Você tem " + idade +
  " anos.";
✅ Template literal
const msg = `Olá, ${nome}!
Você tem ${idade} anos.`;

Convenção de nomenclatura

Em JS usa-se camelCase — primeira letra minúscula, cada palavra seguinte começa com maiúscula:

javascript 
// ✅ Correto
const primeiroNome = "Ana";
let contadorDeCliques = 0;

// ❌ Incorreto
const primeiro_nome = "Ana";   // snake_case — é do Python
const PrimeiroNome = "Ana";   // PascalCase — é para classes
Bloco 03

Lógica de Programação em JS

Você já domina if, loops e arrays de Java/C#. Aqui vamos ver como escrever essas estruturas em JavaScript — a lógica é a mesma, a sintaxe tem pequenas diferenças.

Condicionais — if / else if / else

Idêntico ao Java/C#, sem surpresas:

javascript 
const nota = 85;

if (nota >= 90) {
  console.log("Aprovado com distinção");
} else if (nota >= 70) {
  console.log("Aprovado");
} else {
  console.log("Reprovado");
}
// Saída: "Aprovado"

Switch

Útil quando há muitas condições baseadas em um único valor. O break é obrigatório para não "cair" no próximo case:

javascript 
const dia = 3;

switch (dia) {
  case 1:
    console.log("Domingo");
    break;
  case 2:
    console.log("Segunda");
    break;
  case 3:
    console.log("Terça");
    break;
  default:
    console.log("Outro dia");
}
// Saída: "Terça"

Arrays

Arrays em JS são dinâmicos — podem ter elementos de tipos diferentes e crescem ou encolhem livremente. A indexação começa em 0:

javascript 
const frutas = ["maçã", "banana", "laranja"];

console.log(frutas[0]);        // "maçã"
console.log(frutas.length);    // 3

frutas.push("uva");           // adiciona no final
frutas.pop();                 // remove o último
frutas.unshift("pera");       // adiciona no início
frutas.shift();               // remove o primeiro

Loops — for, while, do...while

javascript — for clássico 
const numeros = [10, 20, 30, 40];

for (let i = 0; i < numeros.length; i++) {
  console.log(numeros[i]);
}
// 10, 20, 30, 40
javascript — while 
let tentativas = 0;

while (tentativas < 3) {
  console.log(`Tentativa ${tentativas + 1}`);
  tentativas++;
}
// Tentativa 1, Tentativa 2, Tentativa 3
javascript — do...while (executa ao menos 1x) 
let j = 10;

do {
  console.log("Executa ao menos uma vez");
  j++;
} while (j < 5);
// Executa 1x mesmo com j = 10 (condição já falsa)
Bloco 04

Funções

Você já conhece métodos de Java/C#. Em JS, funções são cidadãs de primeira classe — podem ser atribuídas a variáveis, passadas como argumentos e retornadas por outras funções.

Declaração tradicional

javascript 
function saudacao(nome) {
  return `Olá, ${nome}!`;
}

console.log(saudacao("Maria")); // "Olá, Maria!"

Arrow Functions — a sintaxe moderna

Introduzidas no ES6, arrow functions são mais concisas e se tornaram o padrão no JS moderno. Esta é uma novidade real em relação ao Java/C#:

javascript — arrow functions 
// Forma completa
const somar = (a, b) => {
  return a + b;
};

// Forma curta — return implícito quando há só uma expressão
const dobro = numero => numero * 2;

// Sem parâmetros
const saudar = () => "Olá!";

console.log(somar(3, 4));  // 7
console.log(dobro(5));    // 10
console.log(saudar());    // "Olá!"

Parâmetros, argumentos e return

javascript 
const calcularImposto = (salario) => {
  const aliquota = 0.15;
  return salario * aliquota; // retorna o valor calculado
};

const imposto = calcularImposto(5000);
console.log(`Imposto: R$ ${imposto}`); // "Imposto: R$ 750"
📌

Se uma função não tiver return, ela retorna undefined automaticamente. Diferente do Java/C# onde funções sem retorno são declaradas como void.

Bloco 05

Objetos

Você já viu POO em Java/C#. Em JS, objetos existem de uma forma mais direta e flexível — sem precisar definir uma classe antes de criar.

Notação literal

Criamos objetos diretamente com chaves {}, sem necessidade de classe:

javascript 
const usuario = {
  nome: "Carlos",
  idade: 32,
  ativo: true,
  endereco: {             // objeto aninhado
    cidade: "São Paulo",
    estado: "SP"
  }
};

Acessando e modificando propriedades

javascript 
// Notação de ponto — mais comum
console.log(usuario.nome);             // "Carlos"
console.log(usuario.endereco.cidade);  // "São Paulo"

// Notação de colchetes — quando a chave é dinâmica
const campo = "nome";
console.log(usuario[campo]);           // "Carlos"

// Modificando e adicionando
usuario.idade = 33;
usuario.email = "carlos@email.com"; // nova propriedade

Métodos — funções dentro de objetos

javascript 
const produto = {
  nome: "Notebook",
  preco: 4500,
  mostrarInfo: function() {
    return `${this.nome} custa R$ ${this.preco}`;
    // 'this' se refere ao próprio objeto
  }
};

console.log(produto.mostrarInfo()); // "Notebook custa R$ 4500"
Bloco 06

O DOM — Document Object Model

O DOM é a ponte entre o JavaScript e o HTML. É através dele que o JS consegue ler, alterar e criar elementos na página em tempo real.

O que é o DOM?

Quando o navegador carrega um HTML, ele cria uma árvore de objetos na memória representando cada elemento. O JavaScript acessa essa árvore para manipular a página:

document
<html>
<head>
<title> "Meu Site"
<body>
<h1 id="titulo"> "Olá!"
<p class="info"> "Texto..."
<button id="btn"> "Clique"

Selecionando elementos

javascript 
// querySelector — recomendado, aceita qualquer seletor CSS
const titulo = document.querySelector("#titulo");
const paragrafo = document.querySelector(".info");
const botao = document.querySelector("button");

// querySelectorAll — retorna todos os elementos
const todosItens = document.querySelectorAll(".item");

// getElementById — legado, mas ainda usado
const el = document.getElementById("titulo");

Alterando conteúdo

javascript 
const titulo = document.querySelector("#titulo");

// textContent — só texto puro (mais seguro)
titulo.textContent = "Novo título!";

// innerHTML — interpreta tags HTML
titulo.innerHTML = "Título em <em>itálico</em>";

// Lendo um valor de input
const campo = document.querySelector("#meu-input");
console.log(campo.value);

Manipulando estilos e classes

javascript 
const caixa = document.querySelector(".caixa");

// .style — altera CSS diretamente (propriedades em camelCase)
caixa.style.backgroundColor = "blue";
caixa.style.fontSize = "20px";

// classList — melhor prática: adicionar/remover classes CSS
caixa.classList.add("ativo");        // adiciona
caixa.classList.remove("oculto");    // remove
caixa.classList.toggle("dark");     // alterna
caixa.classList.contains("ativo");  // verifica — true/false
✅

Prefira classList ao invés de .style sempre que possível. Assim o JS cuida do comportamento e o CSS cuida da aparência — separação de responsabilidades.

Bloco 07

Eventos

Eventos são a essência da interatividade — são as ações do usuário (cliques, digitação, movimento do mouse) às quais o JavaScript responde.

addEventListener

O método addEventListener conecta uma função a um evento de um elemento:

javascript 
const botao = document.querySelector("#meu-botao");

botao.addEventListener("click", () => {
  console.log("Botão clicado!");
});

// elemento.addEventListener(evento, função)

Eventos mais usados

Mouse sai do elemento

Página/recurso carregado

HTML carregado

Campo ativo/inativo

O objeto event

A função de callback recebe automaticamente um objeto com informações sobre o evento:

javascript 
const campo = document.querySelector("#nome");

campo.addEventListener("input", (e) => {
  console.log(e.target.value); // o que o usuário digitou
});

// Prevenindo comportamento padrão (ex: submit recarregar a página)
const form = document.querySelector("form");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // impede o recarregamento
  console.log("Formulário enviado!");
});

Exemplo completo — contador

html + javascript 
<!-- HTML -->
<p id="valor">0</p>
<button id="btn-inc">+1</button>
<button id="btn-dec">-1</button>

<!-- JavaScript -->
let contador = 0;
const display = document.querySelector("#valor");

document.querySelector("#btn-inc")
  .addEventListener("click", () => {
    contador++;
    display.textContent = contador;
  });

document.querySelector("#btn-dec")
  .addEventListener("click", () => {
    if (contador > 0) {
      contador--;
      display.textContent = contador;
    }
  });
Bloco 08

Preparação para Node.js

Até agora o JavaScript rodou no navegador. O Node.js permite rodar JS no servidor — e é aí que entra o back-end. Este bloco é uma introdução ao que vem pela frente.

🌉 A grande virada

O JavaScript nasceu no navegador. Em 2009, o Node.js permitiu rodar JS fora do navegador, direto no sistema operacional — abrindo as portas para back-end, APIs, automações e muito mais com a mesma linguagem.

O que é o Node.js?

🟢

Node.js

Ambiente de execução de JavaScript no servidor. Não é uma linguagem — é como uma "máquina virtual" que roda JS fora do navegador.

📦

npm

Node Package Manager — o gerenciador de pacotes do Node. Permite instalar bibliotecas de terceiros com um comando: npm install.

📁

package.json

O arquivo de configuração do projeto Node. Lista as dependências, scripts e informações do projeto.

Módulos — import e export

No Node, o código é organizado em módulos. Cada arquivo pode exportar funções e importar de outros arquivos ou bibliotecas:

javascript — módulos ES6 
// matematica.js — exportando
export const somar = (a, b) => a + b;
export const subtrair = (a, b) => a - b;

// app.js — importando
import { somar, subtrair } from "./matematica.js";

console.log(somar(5, 3));     // 8
console.log(subtrair(10, 4)); // 6

async / await — introdução

No Node você vai buscar dados de bancos de dados e APIs — operações que levam tempo. O async/await permite esperar por essas operações sem travar o programa:

javascript — async/await 
// async marca a função como assíncrona
const buscarDados = async () => {
  try {
    // await "pausa" aqui até receber a resposta
    const resposta = await fetch("https://api.exemplo.com");
    const dados = await resposta.json();
    console.log(dados);
  } catch (erro) {
    // try/catch captura erros, como o Java
    console.error("Erro:", erro);
  }
};

buscarDados();
🚀

No Módulo 6 você vai usar tudo isso no Node.js para criar sua própria API. Por enquanto, entenda o conceito: async/await é a forma moderna de lidar com operações que levam tempo — como consultas a banco de dados.
